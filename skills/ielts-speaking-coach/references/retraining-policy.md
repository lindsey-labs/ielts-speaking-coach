# One-target retraining policy

## Select the target

Let the learner enter retraining in any of four ways:

- select the latest session;
- select any historical day or question;
- select a saved issue or expression;
- accept the system's recommended target.

Score each unresolved issue:

`priority = exam impact × recurrence × trainability × evidence confidence`

After the learner chooses the source, select exactly one target for that retraining session. Prefer a repeated, high-impact behavior that can improve in 5–12 minutes. Do not force this target into the next normal question-bank session.

## Four-stage ladder

### 1. Isolate

Remove topic difficulty. Ask the learner to produce only the missing language or thinking move.

Example: give one opinion and add one reason beginning with `This is mainly because...`.

### 2. Scaffold

Provide a visible answer frame.

Example:

`claim → because → specific example → result`

Complete two attempts with different questions.

### 3. Timed transfer

Remove the frame. Give an unseen question from the same topic family and apply normal response timing.

### 4. New-topic transfer

Give a question from a different topic. The learner must demonstrate the target without being reminded.

## Status rules

- `new`: detected but not trained.
- `training`: completed isolate or scaffold practice.
- `initially-improved`: passed timed transfer and new-topic transfer once.
- `stable`: passed again after at least one later session.

Do not mark a target stable from repetition of the same answer.

## Failure handling

After three unsuccessful attempts:

1. Reduce task complexity.
2. Show one model.
3. Ask the learner to imitate the structure with different content.
4. Keep the same target; do not add a new weakness.

## Session ending

Return:

- attempts completed;
- best evidence;
- current status;
- the next date or session for rechecking;
- whether the learner should return to normal question practice.
